## Notes

Track launch status in your own project tracker. Keep this file free of passwords, API keys and client secrets — it is committed to the template repo.

## Repo naming

Use the studio slug for both the folder and the GitHub repository, e.g. `saya`, `studio-name`. Each client gets:

- its own GitHub repository
- its own Vercel project
- its own domain or `*.vercel.app` URL
